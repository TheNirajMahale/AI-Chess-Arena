# AI Chess Arena — Flutter Mobile Companion Client

Cross-platform Flutter companion application for the AI Chess Arena platform.

## Features
- **Custom Canvas Chessboard**: High-performance piece rendering with drag-and-drop move previews, square highlights, check indicators, and evaluation bar.
- **Real-Time Reasoning Streams**: Live token-by-token chain-of-thought terminal and WhatsApp-style monologue bubbles.
- **Match Setup & AI Roster**: Configure match duelists, thinking depth chips, move delays, and custom system instructions.
- **Offline Replay Inspector**: Step and auto-scrub through historical matches with time-travel board state inspection.
- **11 Material 3 Theme Presets**: Curated tonal palettes with true OLED dark mode and 6 board styles.

## Development Setup

```bash
# Fetch Flutter dependencies
flutter pub get

# Run static analysis
flutter analyze

# Run unit and widget test suites
flutter test

# Launch on connected device
flutter run
```
